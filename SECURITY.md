# Política de seguridad

## Versiones compatibles

Las correcciones de seguridad se publican para la versión estable más reciente
de Minemories. Si el problema afecta al protocolo compartido, la actualización
puede requerir cambiar juntos el mod Fabric y el plugin Paper.

## Reportar una vulnerabilidad

Usa el [reporte privado de vulnerabilidades de GitHub](https://github.com/Becerritoo/Minemories/security/advisories/new).
No abras una incidencia pública cuando el reporte incluya una forma de evadir
límites, falsificar cámaras o rollos, exponer credenciales o ejecutar código.

Incluye la versión afectada, el impacto, los pasos mínimos para reproducirlo y,
si es posible, una propuesta de mitigación. No adjuntes webhooks, tokens,
`security.yml`, bases de datos ni datos personales reales. Si una credencial ya
se filtró, revócala antes de enviar el reporte.

El alcance y los límites de confianza están documentados en el
[modelo de amenazas](docs/SECURITY.md).
